# MatPlotWonders

MatPlotWonders is a Jupyter Notebook project designed to showcase the power and versatility of data visualization using **Matplotlib** in Python.

## Overview

This notebook includes:
- Basic plotting with Matplotlib.
- Plotting mathematical functions such as sinusoids.
- Customizing plots with labels, legends, and styles.
- Combining multiple plots in a single figure.
- Examples of real-world data visualization techniques.

## Features

1. **Basic Plotting**
   - Learn how to plot simple graphs with minimal code.

2. **Function Visualization**
   - Plot sinusoidal and other mathematical functions using NumPy and Matplotlib.

3. **Styling and Customization**
   - Change colors, markers, line styles.
   - Add titles, labels, and legends.

4. **Multiple Plots**
   - Use subplots to compare different datasets in one figure.

## Requirements

- Python 3.x
- Jupyter Notebook
- NumPy
- Matplotlib

Install dependencies with:
```bash
pip install numpy matplotlib jupyter
```

## How to Run

1. Clone or download this repository.
2. Open a terminal and navigate to the folder containing the notebook.
3. Launch Jupyter Notebook:
```bash
jupyter notebook MatPlotWonders.ipynb
```
4. Run the cells step-by-step to see each visualization.

## Example Output

- Sine and cosine wave plots.
- Styled scatter plots.
- Combined line and bar charts.
